Pastikan admin.html dibuka dari dalam folder website yang lengkap — folder js harus berada di sebelah file ini.

Cara pakai
  1. Klik status yang benar untuk tiap kamar di bawah.
  2. Tekan tombol Salin hasil.
  3. Buka file js/status.js, hapus seluruh isinya, tempel hasil salinan tadi.
  4. Simpan file, lalu unggah ulang ke Netlify.
